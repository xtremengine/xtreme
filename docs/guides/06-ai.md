# AI System

Xtreme Engine provides AI capabilities including pathfinding, perception, and ML inference.

## AI Brain Component

The `AIBrain` is the central component for intelligent agents.

```rust
use xtreme::ai::{AIBrain, AIState, Decision};

// Create a brain
let mut brain = AIBrain::new();

// Configure thinking interval
brain.think_interval = 0.1; // Think every 100ms
```

### AI States

```rust
pub enum AIState {
    Idle,      // Default state, doing nothing
    Patrol,    // Following waypoints
    Chase,     // Pursuing a target
    Attack,    // Engaging a target
    Flee,      // Running away
    Search,    // Looking for something
    Custom(u32), // User-defined states
}
```

### Decisions

```rust
pub enum Decision {
    None,                                // No action
    MoveTo { target: Vec3 },            // Move to position
    Attack { target_entity: Entity },   // Attack entity
    Flee { from: Vec3 },                // Run from position
    Patrol { waypoints: Vec<Vec3> },    // Follow path
    Custom(String),                      // User-defined
}
```

### Brain Update Loop

```rust
fn update_ai(brain: &mut AIBrain, dt: f32) {
    brain.update(dt);

    if brain.should_think() {
        // Make a decision based on current state
        let decision = match brain.state {
            AIState::Idle => decide_idle(brain),
            AIState::Chase => decide_chase(brain),
            AIState::Flee => decide_flee(brain),
            _ => Decision::None,
        };

        brain.decision = decision;
        brain.did_think();
    }

    // Execute current decision
    execute_decision(&brain.decision);
}
```

## A* Pathfinding

Grid-based pathfinding using the A* algorithm.

### Creating a Grid

```rust
use xtreme::ai::{Grid, AStar, Path};

// Create 100x100 grid
let mut grid = Grid::new(100, 100);

// Mark blocked cells (walls, obstacles)
grid.set_blocked(50, 50);
grid.set_blocked(51, 50);
grid.set_blocked(52, 50);

// Or block a range
for x in 40..60 {
    grid.set_blocked(x, 40);
}
```

### Finding Paths

```rust
// Find path from (0,0) to (99,99)
let start = (0, 0);
let goal = (99, 99);

if let Some(path) = AStar::find_path(&grid, start, goal) {
    println!("Path found with {} nodes", path.nodes.len());

    for (x, y) in &path.nodes {
        println!("  Step: ({}, {})", x, y);
    }
} else {
    println!("No path found!");
}
```

### Path Following

```rust
struct PathFollower {
    path: Option<Path>,
    current_index: usize,
    speed: f32,
}

impl PathFollower {
    fn update(&mut self, position: &mut Vec3, dt: f32) {
        if let Some(ref path) = self.path {
            if self.current_index >= path.nodes.len() {
                return; // Path complete
            }

            let (target_x, target_y) = path.nodes[self.current_index];
            let target = Vec3::new(target_x as f32, position.y, target_y as f32);

            // Move towards target
            let direction = (target - *position).normalize_or_zero();
            *position += direction * self.speed * dt;

            // Check if reached waypoint
            if position.distance(target) < 0.5 {
                self.current_index += 1;
            }
        }
    }
}
```

## Perception System

Simulate AI senses for awareness.

### Field of View

```rust
use xtreme::ai::FieldOfView;
use glam::Vec3;

let fov = FieldOfView::new(
    60.0,   // FOV angle in degrees
    20.0,   // View distance
);

// Check if target is visible
let viewer_pos = Vec3::new(0.0, 0.0, 0.0);
let viewer_forward = Vec3::NEG_Z;
let target_pos = Vec3::new(5.0, 0.0, -10.0);

if fov.can_see(viewer_pos, viewer_forward, target_pos) {
    println!("Target is visible!");
}
```

### Sensors

```rust
use xtreme::ai::Sensor;

// Different sensor types
let vision = Sensor::new_vision(60.0, 30.0);  // FOV, range
let hearing = Sensor::new_hearing(15.0);       // Hear radius
let proximity = Sensor::new_proximity(5.0);    // Close range

// Check detections
for sensor in &[vision, hearing, proximity] {
    if sensor.detect(self_pos, self_forward, target_pos) {
        println!("Detected by {:?}!", sensor.kind);
    }
}
```

### Perception Memory

Track what the AI has seen:

```rust
use xtreme::ai::PerceptionMemory;

let mut memory = PerceptionMemory::new();

// Remember seeing a target
memory.record_sighting(
    target_entity,
    target_position,
    current_time,
);

// Query recent sightings
let recent = memory.get_recent_sightings(5.0); // Last 5 seconds

// Check if target was seen
if let Some(sighting) = memory.last_sighting(target_entity) {
    let time_since = current_time - sighting.time;
    println!("Last seen {} seconds ago at {:?}", time_since, sighting.position);
}

// Forget old sightings
memory.forget_older_than(10.0); // Forget after 10 seconds
```

## ML Inference (Optional)

Use trained machine learning models for AI decisions.

**Enable the `ml` feature:**

```toml
[dependencies]
xtreme-engine = { version = "0.1", features = ["ml"] }
```

### Loading Models

```rust
#[cfg(feature = "ml")]
use xtreme::ai::{OnnxModel, ModelInput, ModelOutput};

// Load ONNX model
let model = OnnxModel::load("models/agent.onnx")?;
```

### Running Inference

```rust
// Prepare input (observations)
let observation = vec![
    player_x, player_y, player_z,
    enemy_x, enemy_y, enemy_z,
    health / 100.0,
    ammo / max_ammo,
];

let input = ModelInput::from_vec(observation);

// Run inference
let output = model.infer(&input)?;

// Interpret output (depends on model)
// For discrete actions:
let action = output.argmax(); // 0=idle, 1=move, 2=attack, etc.

// For continuous actions:
let move_x = output.values[0];
let move_y = output.values[1];
```

### Training Pipeline

Typical workflow:

```
1. Define observation/action space
2. Train in Python (PyTorch, Stable-Baselines3)
3. Export to ONNX format
4. Load and run in Xtreme Engine
```

**Python training example:**

```python
# train_agent.py
import torch
from stable_baselines3 import PPO

# Train
model = PPO("MlpPolicy", "YourEnv-v0")
model.learn(total_timesteps=100000)

# Export to ONNX
dummy_input = torch.randn(1, observation_size)
torch.onnx.export(
    model.policy,
    dummy_input,
    "agent.onnx",
    input_names=["observation"],
    output_names=["action"],
)
```

## Example: Complete AI Agent

```rust
use xtreme::core::*;
use xtreme::ai::*;

// Components
struct Agent {
    brain: AIBrain,
    perception: FieldOfView,
    memory: PerceptionMemory,
    path_follower: PathFollower,
}

impl Agent {
    fn new() -> Self {
        Self {
            brain: AIBrain::new(),
            perception: FieldOfView::new(90.0, 25.0),
            memory: PerceptionMemory::new(),
            path_follower: PathFollower::default(),
        }
    }

    fn update(&mut self, self_pos: Vec3, forward: Vec3, targets: &[Vec3], dt: f32, grid: &Grid) {
        // 1. Perception - detect targets
        for &target_pos in targets {
            if self.perception.can_see(self_pos, forward, target_pos) {
                self.memory.record_sighting(0, target_pos, 0.0);
            }
        }

        // 2. Brain update
        self.brain.update(dt);

        if self.brain.should_think() {
            // Make decision based on state and memory
            self.brain.decision = self.decide(&self_pos, grid);
            self.brain.did_think();
        }

        // 3. Execute decision
        // ...
    }

    fn decide(&self, self_pos: &Vec3, grid: &Grid) -> Decision {
        match self.brain.state {
            AIState::Idle => {
                // Check if we've seen anything
                if let Some(sighting) = self.memory.last_sighting(0) {
                    return Decision::MoveTo { target: sighting.position };
                }
                Decision::None
            }
            AIState::Chase => {
                if let Some(sighting) = self.memory.last_sighting(0) {
                    // Pathfind to target
                    let start = (self_pos.x as i32, self_pos.z as i32);
                    let goal = (sighting.position.x as i32, sighting.position.z as i32);

                    if let Some(path) = AStar::find_path(grid, start, goal) {
                        // Return first waypoint
                        if let Some(&(x, z)) = path.nodes.get(1) {
                            return Decision::MoveTo {
                                target: Vec3::new(x as f32, 0.0, z as f32)
                            };
                        }
                    }
                }
                Decision::None
            }
            _ => Decision::None,
        }
    }
}
```

## Performance Tips

1. **Limit Pathfinding**: Don't pathfind every frame - cache paths
2. **LOD AI**: Simpler AI for distant agents
3. **Batch Perception**: Check visibility in batches, not every target every frame
4. **Async ML**: Run inference asynchronously if possible
5. **Spatial Queries**: Use spatial grid for perception checks
