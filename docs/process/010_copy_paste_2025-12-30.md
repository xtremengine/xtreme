## Funcionalidades

### Atalhos

- **Ctrl+C**: Copy - Copia objetos selecionados
- **Ctrl+X**: Cut - Copia e deleta objetos selecionados
- **Ctrl+V**: Paste - Cola objetos com offset
- **Ctrl+A**: Select All - Seleciona todos os objetos visiveis

### Comportamento

- Copy salva clone dos objetos no clipboard
- Paste cria novos objetos com:
  - Novo ID unico
  - Nome com sufixo " (copy)"
  - Offset de posicao (1, 0, 1)
- Cut usa copy + delete
- Select All adiciona todos objetos visiveis a selecao

### Menu Edit

- Cut (Ctrl+X)
- Copy (Ctrl+C)
- Paste (Ctrl+V)
- Delete (multi-select suportado)
- Duplicate
