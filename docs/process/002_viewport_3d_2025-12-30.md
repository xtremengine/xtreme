# Process: Viewport 3D com Grid e Meshes

**Data:** 2025-12-30
**Fase:** 2 - Viewport 3D

## Objetivo

Implementar viewport 3D com render-to-texture para exibicao no egui, incluindo grid infinito e renderizacao de cubos.

## Arquivos Criados/Modificados

### Novos Arquivos

1. `src/shaders/grid.wgsl` (~95 linhas)
   - Shader WGSL para grid infinito no plano XZ
   - Grid menor (cada 1 unidade) e maior (cada 10 unidades)
   - Eixos coloridos: X vermelho, Z azul
   - Fade com distancia da camera

2. `src/editor/viewport.rs` (~400 linhas)
   - Sistema de render-to-texture para egui
   - Pipelines separados: grid e meshes
   - Uniforms para camera e objetos
   - Integracao com egui via `register_native_texture`

### Arquivos Modificados

1. `src/render/mesh.rs`
   - Adicionado `GpuMesh` com vertex/index buffers
   - Cubo completo com 6 faces (24 vertices, 36 indices)
   - Metodos `draw()` e `draw_instanced()`

2. `src/render/camera.rs`
   - Adicionado `position()` (alias para eye_position)
   - Adicionado `view_projection_matrix()`

3. `src/editor/app.rs`
   - Integrado viewport no painel central
   - Controles de camera no Inspector
   - Menu Create para adicionar cubos
   - Status bar com tamanho do viewport

4. `src/render/egui_integration.rs`
   - Adicionado `renderer_mut()` para acesso ao egui-wgpu

5. `src/editor/mod.rs`
   - Exportado modulo `viewport`

## Arquitetura do Viewport

```
Viewport
├── render_texture (Rgba8UnormSrgb)
├── depth_texture (Depth32Float)
├── grid_pipeline
│   ├── grid.wgsl shader
│   └── GridUniforms (view_proj, camera_pos, grid_scale)
├── mesh_pipeline
│   ├── basic.wgsl shader
│   └── Uniforms (view_proj, model, color)
└── cube_mesh (GpuMesh)
```

## Render Loop

1. Update uniforms (camera, objetos)
2. Clear pass (cor de fundo + depth)
3. Draw meshes (cubos)
4. Draw grid (com alpha blending)
5. Egui exibe textura no CentralPanel

## Funcionalidades do Editor

- **Menu Create > Cube**: Adiciona cubo na origem
- **Menu Create > Random Cubes**: Adiciona 5 cubos aleatorios
- **Menu View**: Presets de camera (Reset, Top, Front)
- **Inspector > Camera**: Distance, Pitch, Yaw editaveis
- **Status Bar**: Frame count, entities, cubes, viewport size

## Resultado

- Viewport 3D funcional com:
  - Grid infinito com eixos coloridos
  - Cubos laranja renderizando
  - Camera isometrica controlavel
  - Resize dinamico do viewport
