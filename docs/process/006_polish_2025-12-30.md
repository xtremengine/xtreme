# Fase 6: Polish - Undo/Redo, Hotkeys, Save/Load

**Data:** 2025-12-30
**Status:** Concluido

## Objetivo

Adicionar funcionalidades de polish ao editor:
1. Undo/Redo com Command Pattern
2. Hotkeys customizaveis
3. Save/Load de cenas (RON/JSON)

## Arquivos Criados

### src/editor/commands.rs (~230 linhas)

Sistema de Undo/Redo usando Command Pattern:

**Enum Command:**
- `Transform` - posicao, rotacao, escala (old/new)
- `Create` - dados do objeto criado
- `Delete` - dados do objeto deletado
- `Rename` - nome antigo e novo
- `ChangeColor` - cor antiga e nova
- `ToggleVisibility` - estado anterior
- `Batch` - grupo de comandos

**Struct CommandHistory:**
- `undo_stack` / `redo_stack` - pilhas de comandos
- `execute()` - adiciona comando ao historico
- `undo()` / `redo()` - navega no historico
- `begin_drag()` / `update_drag()` / `end_drag()` - tracking de drag
- `can_undo()` / `can_redo()` - verifica disponibilidade
- `peek_undo()` / `peek_redo()` - visualiza proximo comando

### src/editor/shortcuts.rs (~350 linhas)

Sistema de atalhos de teclado customizaveis:

**Structs:**
- `Modifiers` - ctrl, shift, alt
- `Shortcut` - key + modifiers
- `KeyCode` - enum com todas as teclas suportadas

**Enum EditorAction:**
- File: NewScene, OpenScene, SaveScene, SaveSceneAs
- Edit: Undo, Redo, Cut, Copy, Paste, Delete, Duplicate, SelectAll
- Tools: SelectTool, MoveTool, RotateTool, ScaleTool
- View: FocusSelected, FrameAll, ResetCamera, TopView, FrontView, SideView
- Object: CreateCube, CreateEmpty, ToggleVisibility

**Struct ShortcutManager:**
- `bindings` - mapa shortcut -> action
- `bind()` / `unbind()` - gerencia bindings
- `process_input()` - processa input do egui
- `get_shortcut_text()` - texto formatado para menus

**Atalhos padrao:**
| Atalho | Acao |
|--------|------|
| Ctrl+Z | Undo |
| Ctrl+Shift+Z / Ctrl+Y | Redo |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save As |
| Ctrl+O | Open |
| Ctrl+N | New |
| Del | Delete |
| Ctrl+D | Duplicate |
| Q/W/E/R | Select/Move/Rotate/Scale |
| F | Focus Selected |
| 1/3/7 | Front/Side/Top View |
| H | Toggle Visibility |

### src/editor/scene.rs (~200 linhas)

Sistema de Save/Load de cenas:

**Structs:**
- `SceneObjectData` - objeto serializavel
- `SceneData` - formato do arquivo de cena
- `SceneManager` - gerencia estado da cena atual

**Formatos suportados:**
- `.ron` - RON (Rusty Object Notation) - default
- `.json` - JSON

**SceneData:**
- `version` - versao do formato
- `name` - nome da cena
- `camera_target` / `camera_distance` - configuracao da camera
- `objects` - lista de objetos

**SceneManager:**
- `current_path()` - caminho do arquivo atual
- `scene_name()` - nome da cena
- `is_dirty()` - tem alteracoes nao salvas
- `mark_dirty()` / `mark_clean()` - controle de estado

## Interface

### Menu File
- New Scene (Ctrl+N)
- Open... (Ctrl+O)
- Save (Ctrl+S) - desabilitado se nao tem path
- Save As... (Ctrl+Shift+S)
- Exit

### Menu Edit
- Undo [descricao] (Ctrl+Z)
- Redo [descricao] (Ctrl+Shift+Z)
- Delete Selected (Del)
- Duplicate Selected (Ctrl+D)

### Status Bar
- Nome da cena com indicador de dirty (*)
- Contadores de undo/redo

### File Dialog
- Window modal para Open/Save
- Campo de texto para caminho
- Suporta .ron e .json

## Teste

```bash
cargo run --example editor
```

1. Crie/mova alguns objetos
2. Pressione Ctrl+Z para desfazer
3. Pressione Ctrl+Shift+Z para refazer
4. File > Save As... e salve como "test.ron"
5. File > New Scene
6. File > Open... e abra "test.ron"

```ron
SceneData(

    name: "test",
    camera_target: Some((0.0, 0.0, 0.0)),
    camera_distance: Some(20.0),
    objects: [

            name: "Cube 0",
            position: (0.0, 0.5, 0.0),
            rotation: (0.0, 0.0, 0.0),
            scale: (1.0, 1.0, 1.0),
            color: (0.8, 0.3, 0.3, 1.0),
            visible: true,
        ),
    ],
)
```
