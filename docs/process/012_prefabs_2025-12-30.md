## Estrutura

```rust
pub struct Prefab {
    pub name: String,
    pub objects: Vec<PrefabObject>,
    pub version: u32,
}

pub struct PrefabObject {
    pub name: String,
    pub local_position: [f32; 3],  // Relativo ao centro
    pub rotation: [f32; 3],
    pub scale: [f32; 3],
    pub color: [f32; 4],
    pub visible: bool,
}
```

## Funcionalidades

### Criacao
- Menu Create > Prefab > Create from Selection
- Dialog para nome do prefab
- Calcula centro automaticamente
- Posicoes relativas ao centro

### Instanciacao
- Menu Create > Prefab > [Lista de prefabs]
- Instancia na posicao do target da camera
- Cria novos IDs para cada objeto
- Suporta undo (Command::Create para cada)

### Persistencia
- Save/Load em formato RON ou JSON
- Metodos save_prefab() e load_prefab()

## UI

- Submenu Prefab no menu Create
- Dialog modal para criar prefab
- Lista de prefabs disponiveis
