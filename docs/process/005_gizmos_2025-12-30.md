# Fase 5: Gizmos de Manipulacao

**Data:** 2025-12-30
**Status:** Concluido

## Objetivo

Implementar gizmos 3D para manipulacao visual de objetos diretamente no viewport.

## Arquivos Criados

### src/shaders/gizmo.wgsl (~40 linhas)
Shader simples para gizmos com cor por vertice:
- `GizmoUniforms` - view_proj e model matrix
- `vs_main()` - transformacao de vertices
- `fs_main()` - cor direta sem lighting

### src/editor/gizmos.rs (~530 linhas)
Sistema completo de gizmos:

**Enums:**
- `GizmoAxis` - None, X, Y, Z, XY, XZ, YZ, XYZ
- `GizmoMode` - Translate, Rotate, Scale

**Structs:**
- `GizmoVertex` - position + color (Pod/Zeroable)
- `GizmoDelta` - translation, rotation, scale deltas
- `Gizmo` - estado e logica completa

**Funcoes principais:**
- `generate_vertices()` - gera geometria para cada modo
- `hit_test()` - ray casting contra eixos/aneis
- `begin_drag()` / `update_drag()` / `end_drag()` - manipulacao
- `project_ray_to_axis()` - projeta ray para plano do eixo
- `constrain_to_axis()` - restringe delta ao eixo ativo

**Geometria:**
- Translate: linhas + cones (setas) + quadrados (planos)
- Rotate: 3 circulos (48 segmentos cada)
- Scale: linhas + cubos nas pontas + cubo central

**Cores padrao:**
- X: vermelho `[0.9, 0.2, 0.2, 1.0]`
- Y: verde `[0.2, 0.9, 0.2, 1.0]`
- Z: azul `[0.2, 0.2, 0.9, 1.0]`
- Hover: amarelo `[1.0, 0.9, 0.2, 1.0]`

## Funcionalidades

### Ferramentas (atalhos Q/W/E/R)
- **Select (Q)**: Sem gizmo, apenas selecao
- **Move (W)**: Gizmo de translacao com setas e planos
- **Rotate (E)**: Gizmo de rotacao com aneis
- **Scale (R)**: Gizmo de escala com cubos

### Interacao
- Hover: eixo fica amarelo
- Click+Drag: arrasta no eixo selecionado
- Planos XY/XZ/YZ: movimento em 2 eixos (translate)
- Centro XYZ: rotacao livre ou escala uniforme

### Escala Adaptativa
Gizmo mantem tamanho constante na tela:
```rust
let gizmo_scale = camera.distance * 0.08;
```

## Bugfix: Gizmos nao respondiam ao drag

**Data:** 2025-12-30

### Problema
Gizmos apareciam na tela mas nao era possivel arrastar para manipular objetos.

### Causas Identificadas

1. **Threshold muito pequeno no hit_test** (linha 418)
   - `scale * 0.15` resultava em ~0.24 unidades (muito pequeno)
   - Corrigido para `scale * 0.25`

2. **Calculo incorreto em ray_line_distance** (linhas 791-796)
   - O parametro `t` nao estava normalizado corretamente
   - Corrigido para usar `t / line_len` e interpolar com vetor original

3. **Threshold de delta muito restritivo** (linha 609)
   - `0.0001` ignorava movimentos pequenos
   - Reduzido para `0.000001` para movimento mais suave

### Arquivos Modificados
- `src/editor/gizmos.rs`: 3 correcoes (~10 linhas)
